## ⚡ How to use a drop
1. Open the repo → **Code → Download ZIP** (or **Use this template**)
2. Open `index.html`, edit the `CONFIG` block at the top
3. Publish for free with **GitHub Pages** (Settings → Pages) or **Vercel**

Every repo has its own README with step-by-step instructions.
